# سامانه مدیریت فایل‌های ملکی — گروه مشاورین املاک اخلاصی

سامانه‌ای ساده، سریع و کاملاً استاتیک (بدون نیاز به سرور) برای ثبت و جست‌وجوی
فایل‌های **فروش و اجارهٔ آپارتمان، ویلا و زمین**، مخصوص تیم مشاوران. مستقیم
روی **گیت‌هاب پیجز (GitHub Pages)** قابل انتشار است.

## ویژگی‌ها
- صفحهٔ ورود با نام کاربری/رمز عبور قبل از دسترسی به فایل‌ها
- ثبت، ویرایش، حذف و مشاهدهٔ جزئیات هر فایل با کد فایل خودکار (مثل `EKH-1005`)
- جست‌وجوی آنی در عنوان، کد فایل، منطقه، آدرس و توضیحات
- فیلتر بر اساس نوع معامله (فروش/اجاره)، نوع ملک (آپارتمان/ویلا/زمین) و وضعیت
- مرتب‌سازی بر اساس جدیدترین، قدیمی‌ترین، گران‌ترین و ارزان‌ترین
- آمار لحظه‌ای در نوار کناری
- خروجی و ورودی JSON برای پشتیبان‌گیری و انتقال داده بین مرورگرها
- طراحی اختصاصی با هویت بصری «سند و مهر»، راست‌به‌چپ، فونت وزیرمتن

## نحوهٔ انتشار روی گیت‌هاب پیجز
۱. یک ریپازیتوری جدید در گیت‌هاب بسازید (ترجیحاً Private اگر داده‌ها حساس‌اند).
۲. تمام فایل‌های این پوشه (`index.html`، پوشهٔ `assets`) را به ریپازیتوری push کنید.
۳. به مسیر **Settings → Pages** بروید و در بخش Source گزینهٔ
   `Deploy from a branch` را انتخاب و شاخهٔ `main` و پوشهٔ `/root` را تنظیم کنید.
۴. بعد از چند دقیقه، آدرسی مثل
   `https://username.github.io/repo-name/` در دسترس خواهد بود.

## تغییر نام کاربری و رمز عبور
کاربران مجاز در ابتدای فایل `assets/app.js` تعریف شده‌اند:

```js
const USERS = [
  { username: "admin", password: "ekhlasi1404", displayName: "مدیر سامانه" },
  { username: "reza",  password: "reza1404",   displayName: "رضا احمدی" },
];
```

برای افزودن مشاور جدید، یک خط دیگر به همین شکل اضافه کنید. رمزهای پیش‌فرض را
حتماً قبل از انتشار عمومی تغییر دهید.

## نکتهٔ مهم دربارهٔ امنیت و ذخیره‌سازی
- چون این سامانه کاملاً استاتیک است (بدون بک‌اند)، نام کاربری/رمز عبور در
  همان فایل جاوااسکریپت قرار دارد و برای کاربر حرفه‌ای قابل مشاهده است. این
  روش برای **کنترل دسترسی داخلی تیم** مناسب است، نه برای داده‌های بسیار حساس
  یا عمومی‌کردن فایل. اگر امنیت سطح بالاتر لازم است، بعداً می‌توان یک بک‌اند
  واقعی (مثل Firebase Auth یا Supabase) اضافه کرد.
- فایل‌های ملکی در **localStorage مرورگر** ذخیره می‌شوند؛ یعنی هر کاربر روی
  مرورگر/دستگاه خودش داده دارد و بین دستگاه‌ها هم‌گام (sync) نمی‌شود. برای
  اشتراک‌گذاری بین اعضای تیم، از دکمه‌های **خروجی/ورودی JSON** در نوار کناری
  استفاده کنید، یا در آینده یک پایگاه دادهٔ ابری به برنامه متصل کنید.

## ساختار فایل‌ها
```
index.html          صفحهٔ ورود + پوستهٔ اصلی برنامه
assets/style.css     تمام استایل‌ها و توکن‌های طراحی
assets/app.js        منطق برنامه (احراز هویت، ذخیره‌سازی، فیلتر/جست‌وجو، CRUD)
```

## اجرای محلی
نیازی به نصب چیزی نیست؛ کافیست `index.html` را در مرورگر باز کنید، یا با یک
سرور سادهٔ محلی اجرا کنید:

```bash
npx serve .
# یا
python3 -m http.server 8000
```
